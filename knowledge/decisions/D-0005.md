# D-0005 — A protocol gun advertises the vanilla crossbow hold

**Decision:** a mixin on `Pillager.getArmPose` returns `CROSSBOW_HOLD` when
`RangedWeapons.resolve` recognizes the main-hand item. Every other item follows
vanilla. No gun-mod classes or fake use state enter the implementation. The
Another Gun Mod profiles declare optional protocol grip metadata for consumers.

**Why:** setting aggression alone leaves a gun in the wrong illager pose;
Fresh Animations understands the game's crossbow hold. This applies to both
grips: a distinct one-handed illager animation is not introduced by the pose signal.

**Verification:** a real-server regression failed on the old code with an idle
pillager holding the profiled stick. The test now covers idle/aggressive protocol
weapon, crossbow, unrelated item and empty hand. Ranged Weapons Mod's observer
booth checks the client pose and renders the gun with and without Fresh Animations.
