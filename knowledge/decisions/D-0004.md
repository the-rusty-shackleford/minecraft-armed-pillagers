# D-0004 — Ranged Weapons Mod's guns ship as loadouts in this jar, weighted by how much they hurt

**Decision**: The shipped `pillager_loadouts` table gains Ranged Weapons
Mod's five guns, each entry guarded by `neoforge:mod_loaded
rangedweaponsmod` as the Another Gun Mod entries are guarded by theirs:
pistol 60, shotgun 20, rifle 30, scoped rifle 12, machine gun 6. With both
mods present at the default armed chance that is revolver 4.2%, pistol
3.2%, AGM rifle 2.7%, rifle 1.6%, shotgun 1.1%, AGM shotgun 0.8%, scoped
rifle 0.6%, machine gun 0.3% of pillager spawns. The machine gun entry is
inert until `automatic` is taken off `deniedClasses`; the default config
keeps refusing it, and the server that wants it says so in its own config.

**Why**: Rusty, 2026-09-08: "I do want pillagers to have a chance to spawn
our guns, where lower damage weapons like pistols are slightly more common
and higher damage weapons are more rare. In a perfect world they'd even
carry a machine gun, but that would be a very rare chance to spawn (like
less than 1%)." The weights order the guns by damage per hit and per
second -- pistol, then shotgun and rifle, then the scoped rifle, then the
machine gun -- and the machine gun's 0.3% is one pillager in about three
hundred. The entries live here rather than in Ranged Weapons Mod because
this jar already holds the one table a reader consults for who carries
what (D-0002), and a weight change is a data edit either way.

**Alternatives rejected**: *Ranged Weapons Mod shipping its own entries*
-- two tables to read to know the mix. *A datapack in the server pack* --
right for a server's own taste, wrong for the default every server gets.
*Denying the machine gun for good* -- Rusty wants it rare, not absent;
`deniedClasses` remains the operator's switch.

**Follow-ups**: none.
